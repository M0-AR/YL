JavaFX Basics

A JavaFX window is a tree of nodes: the stage is the window, the scene is its content, and layout panes decide where children sit.

~45 minLayout lab3 objectives5 subgoals
  • Describe the stage, scene, and scene-graph roles in a JavaFX application.
  • Choose a layout pane that matches a simple dashboard arrangement.
  • Explain how a bound property updates a control without manual refresh code.

LessonSubgoals

Read the subgoals first. Each one is a small, checkable idea that the worked example and the playground will use.

  1. Stage, scene, root

    A Stage is the top-level window. A Scene holds one root node. The root is usually a pane whose children form the scene graph.

  2. Panes own placement

    A GridPane places children by column and row. An HBox places them in a row. The pane, not the child, decides the geometry.

  3. Nodes are styled, not painted

    A Label, Button, and Circle are all nodes. You change their state through properties; the toolkit renders them.

  4. Properties can be observed

    A property holds a value and notifies listeners when it changes. A binding expresses a dependent value, such as a label that always shows a counter.

  5. The launch thread owns the UI

    JavaFX creates the application thread. Long work belongs on a background thread; UI updates return to the application thread.

Worked exampleDashboardShell: four nodes, one grid

The layout is the lesson. Read the column and row indexes before reading the text inside each control.

public class DashboardShell extends Application {
    @Override
    public void start(Stage stage) {
        Label title = new Label("Revenue");
        Label value = new Label("$12,480");
        Button refresh = new Button("Refresh");
        GridPane grid = new GridPane();
        grid.setHgap(12);
        grid.setVgap(8);
        grid.add(title, 0, 0);
        grid.add(value, 0, 1);
        grid.add(refresh, 1, 0, 1, 2);
        stage.setScene(new Scene(grid, 320, 180));
        stage.show();
    }
}

  1. Application shell

    Extending Application lets the launcher create the stage and call start on the JavaFX application thread.

  2. Leaf nodes

    Labels and a button are controls: nodes with skin, focus behavior, and properties. They do not know their position yet.

  3. Layout container

    GridPane is a container. Gap settings affect the space between cells, not the space inside a control.

  4. Cell assignment

    The first two adds use column, row. The button spans one column and two rows, so it occupies the right side of both rows.

  5. Scene and show

    The scene gives the root a size. Until show runs, the stage exists but no window is visible.

Predict, then observe

Before you step: What happens if the button is added with grid.add(refresh, 0, 0) after the title?

Two children occupy the same cell. The later child is drawn on top, so the title is hidden or overlapped. A grid cell can hold multiple nodes, but that is rarely the layout you want.
