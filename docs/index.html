The short version

A classic Java curriculum, rebuilt as a working product.

This is not a folder of answers. It is a navigable engineering atlas: read the idea, run the code, move the sliders, break the algorithm, and watch the structure respond. Use it to learn Java from scratch, to refresh the fundamentals before an interview, or to evaluate how a real system is put together.

Business leaders

Straight answers

Questions people actually ask.

Is this the textbook?

No. This is an independent companion project. It does not contain or redistribute the book’s chapters, figures, or exercise text. It contains code, original lessons, and interactive labs built around the same topic sequence. The textbook remains the work of its author and publisher.

Do I need Java installed to use the site?

No. Every lab is HTML, CSS, and JavaScript running in your browser. You only need a JDK when you want to compile and run the Java files in src/ or the companion examples.

Which Java version does the code target?

The original chapter files are written for Java 8–10 and some GUI examples use JavaFX. The new companion examples target Java 17 and are kept dependency-free so they compile with a standard JDK.

Are all 439 files verified?

They are organized by chapter and written to run independently. The companion code is compiled automatically. If you find a file that needs an environment-specific database or GUI runtime, the chapter notes explain what it expects.

Can I use this for teaching or commercial training?

Yes, under the MIT license for the original code and companion material. Keep the copyright notice, and do not imply endorsement by the textbook’s author or publisher. For the textbook itself, obtain the book and its permissions from the publisher.

How is the live demo built?

Each lab is a standalone static page. The showcase loads the real page in an iframe when you select its tab, so you are interacting with the product itself. The “Open full screen” link opens the same page without the frame.

Can I contribute a chapter or a lab?

Yes. Open an issue describing the chapter or concept, then submit a focused pull request. Keep the code self-contained, include a short explanation, and do not paste copyrighted exercise text.
