Internationalization

Internationalization is the discipline of keeping text, formatting, and assumptions about locale out of the code path.

~45 minData pipeline3 objectives5 subgoals
  • Externalize user-visible text into resource bundles.
  • Format numbers, currency, and dates with an explicit locale.
  • Explain why string concatenation is a poor way to build translated messages.

LessonSubgoals

Read the subgoals first. Each one is a small, checkable idea that the worked example and the playground will use.

  1. Locale is a bundle of conventions

    A locale carries language, country, and variant. It affects formatting and text lookup, not just translation.

  2. Resource bundles hold text

    A base bundle plus locale-specific bundles let the same key resolve differently. Missing keys fall back rather than crash.

  3. Format with the locale

    NumberFormat, DateFormat, and Intl-style APIs know decimal separators, currency symbols, and date order.

  4. Do not concatenate grammar

    Word order and plural rules differ. A message pattern with placeholders lets translators control the sentence.

  5. Sorting is locale-sensitive

    Collation can order accented letters differently. A binary string sort is not a user-visible alphabetical order.

Worked examplePriceTag: one value, several conventions

The number is the same; the representation changes with the locale. The currency is part of the format, not the text.

double price = 1234.5;
Locale germany = Locale.GERMANY;
NumberFormat currency = NumberFormat.getCurrencyInstance(germany);
String formatted = currency.format(price);
ResourceBundle bundle = ResourceBundle.getBundle("messages", germany);
String label = bundle.getString("price.label");
System.out.println(label + ": " + formatted);

  1. The value

    The double is locale-free. It has no comma, dot, or symbol until formatting.

  2. Choose the locale

    Germany implies German text conventions and the euro currency for this format.

  3. Format the number

    The formatter inserts the grouping separator, decimal separator, and currency symbol appropriate to the locale.

  4. Load the text

    The bundle resolves the key to German text. A missing German bundle would fall back to the base bundle.

  5. Compose the message

    The label and value are separate. A full message pattern would be even better for grammar.

Predict, then observe

Before you step: Why is "Total: " + price not internationalized even if the label is translated?

The number uses the default locale and a fixed decimal point. The label translation does not change number formatting or word order.

PracticeRebuild the program

A Parsons problem: the lines are correct, but the order is not. Rearrange them until the program would compile and behave as described.
