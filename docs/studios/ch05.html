Loops

A loop is a promise: initialization, a guard, a body, and an update that moves toward termination.

~40 minExecution trace3 objectives5 subgoals
  • Trace a for loop and state how many times the body runs.
  • Choose between for, while, and do-while for a given task.
  • Diagnose an off-by-one error from the guard and the update.

LessonSubgoals

Read the subgoals first. Each one is a small, checkable idea that the worked example and the playground will use.

  1. Every counting loop has four parts

    Initialize the counter, test the guard, run the body, then update. Missing or misordering the update creates an infinite loop or an off-by-one result.

  2. The guard is checked before each iteration

    A for loop is a while loop with the pieces in one line. When the guard becomes false, the body is skipped entirely.

  3. The update moves the state

    i++ changes the counter after the body. If the body also changes i, reasoning about termination becomes harder.

  4. do-while runs at least once

    The condition is checked after the body. Use it when the first attempt must happen before you can decide whether to repeat.

  5. Nested loops multiply work

    An outer loop of n iterations containing an inner loop of n iterations performs about n² body executions.

Worked exampleLoopLedger: sum 1 through 4

The output is 10. The interesting part is the state just before the guard fails.

int sum = 0;
for (int i = 1; i <= 4; i++) {
    sum += i;
}
System.out.println(sum);

  1. Initialize

    sum is 0 and i is 1. The guard 1 <= 4 is true.

  2. Iteration 1

    Add 1, then increment to 2. Sum is 1.

  3. Iteration 2

    Add 2, then increment to 3. Sum is 3.

  4. Iteration 3

    Add 3, then increment to 4. Sum is 6.

  5. Iteration 4

    Add 4, then increment to 5. Sum is 10.

  6. Guard fails

    5 <= 4 is false, so the body is skipped and the loop exits.

Predict, then observe

Before you step: How many times does the body run if the guard is i < 4 instead?

Three times, for i = 1, 2, 3. The sum becomes 6, not 10.

PracticeRebuild the program

A Parsons problem: the lines are correct, but the order is not. Rearrange them until the program would compile and behave as described.
