Graphs and Applications

A graph is a set of relationships; traversal is the discipline of visiting each relationship exactly once.

~55 minGraph lab3 objectives5 subgoals
  • Represent an undirected graph with adjacency lists and an edge set.
  • Trace breadth-first and depth-first search from a start vertex.
  • Explain why a visited set is required and what it prevents.

LessonSubgoals

Read the subgoals first. Each one is a small, checkable idea that the worked example and the playground will use.

  1. Vertices and edges

    A graph has vertices and edges. An undirected edge appears in both adjacency lists; a directed edge appears only in the source list.

  2. Adjacency lists scale with edges

    Each vertex stores its neighbors. Total storage is O(V + E), which is efficient for sparse graphs.

  3. BFS uses a queue

    Visit the start, enqueue its unvisited neighbors, then process the queue in order. BFS discovers vertices by increasing distance in unweighted graphs.

  4. DFS uses a stack or recursion

    Follow one path as far as possible, then backtrack. DFS is natural for connectivity, cycles, and topological ordering.

  5. Visited prevents cycles

    Without a visited set, a cycle sends the traversal around forever. Mark a vertex when it is discovered, not when it is removed.

Worked exampleBreadthFirst: six vertices, two levels

The queue order is the discovery order. A vertex enters the queue once, when it is first seen.

void bfs(Map<String, List<String>> graph, String start) {
    Set<String> seen = new HashSet<>();
    Queue<String> queue = new ArrayDeque<>();
    seen.add(start);
    queue.add(start);
    while (!queue.isEmpty()) {
        String current = queue.remove();
        System.out.print(current + " ");
        for (String next : graph.get(current)) {
            if (seen.add(next)) queue.add(next);
        }
    }
}

  1. Start at A

    A is marked seen before it is enqueued. This prevents a later edge from adding it twice.

  2. Process A

    A's neighbors B and D are unvisited, so both enter the queue and are marked.

  3. Process B

    B's neighbors include A, which is already seen. C and E are new, so they join the queue.

  4. Process D

    D's neighbors are already seen or already queued. The queue order keeps the traversal level by level.

  5. Process C, E, F

    Each vertex is printed once. The visited set, not the graph, guarantees termination.

Predict, then observe

Before you step: If seen.add(start) were removed, what could happen in a graph with a cycle?

The start could be enqueued again from a neighbor, and the traversal could loop or at least duplicate work. Cycles break naive traversal.
