Inheritance and Polymorphism

The compiler checks the declared type; the runtime chooses the override.

~45 minExecution trace3 objectives5 subgoals
  • Trace a virtual method call from the declared type to the runtime type.
  • Distinguish overriding from overloading.
  • Use super to reuse a parent's contract without duplicating its state.

LessonSubgoals

Read the subgoals first. Each one is a small, checkable idea that the worked example and the playground will use.

  1. A subtype is substitutable

    A Dog can be used wherever an Animal is expected. The declared type controls which members are visible.

  2. Overrides are chosen at runtime

    The actual object's class supplies the method body. This is dynamic dispatch.

  3. Overloads are chosen at compile time

    Parameter types decide which overload is called. The runtime type of an argument does not participate.

  4. super calls the parent version

    A subclass can extend behavior instead of replacing it. The parent's constructor runs before the child's body.

  5. Protected is a package-and-subclass boundary

    Use the narrowest access that still allows the subclass to do its job.

Worked exampleDispatch: one reference, two types

The variable is declared as Animal but refers to a Dog. The call still reaches Dog.speak.

class Animal {
    String speak() { return "..."; }
}
class Dog extends Animal {
    @Override String speak() { return "Woof"; }
}
public class Dispatch {
    public static void main(String[] args) {
        Animal pet = new Dog();
        System.out.println(pet.speak());
    }
}

  1. Declared type

    pet is visible as an Animal. Only Animal's members can be called through it.

  2. Runtime type

    The object was created with new Dog(), so its class is Dog.

  3. Virtual call

    The JVM looks up speak() on the runtime class and finds Dog's override.

  4. Return

    The override returns "Woof", even though the call was written against Animal.

Predict, then observe

Before you step: If Dog added a method fetch() that Animal does not have, could pet.fetch() compile?

No. The compiler only sees the declared type Animal, which has no fetch method.
