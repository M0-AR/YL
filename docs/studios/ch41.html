Red-Black Trees

A red-black tree encodes 2-4 balance as colors: no red-red parent-child pair, and every root-to-leaf path has the same black height.

~55 minStructure viewer3 objectives5 subgoals
  • State the red-black invariants and check them on a small tree.
  • Trace a recoloring and the rotation that follows.
  • Explain how red-black rules correspond to 2-4 tree nodes.

LessonSubgoals

Read the subgoals first. Each one is a small, checkable idea that the worked example and the playground will use.

  1. Colors encode structure

    A black node with red children represents a 4-node. A black node with one red child represents a 3-node. Colors store multiway information in a binary tree.

  2. No red-red edge

    A red node cannot have a red parent. This prevents long runs of unbalanced nodes and bounds the height.

  3. Black height is uniform

    Every path from a node to a null leaf passes through the same number of black nodes. That is the balance guarantee.

  4. Recolor first, rotate second

    If the parent and uncle are red, recolor them black and the grandparent red. If the uncle is black, rotate to restore the shape.

  5. The root is black

    Recoloring the root black after insertion preserves the invariants and does not change the black-height relationship.

Worked exampleInsert 25: red parent, red child

The new node is red. The fix depends on the uncle's color, not on the new node alone.

// tree: 20 black, 10 black, 30 red
// insert 25 as the left child of 30
// 30 is red and 25 is red: violation
// uncle is 10, which is black
// rotate right at 30, then recolor
// root remains black

  1. Start

    The tree is balanced: black root 20, black 10, red 30. Every path has the same black height.

  2. Insert red 25

    New nodes start red. 25 is less than 30, so it becomes the left child.

  3. Detect red-red

    30 is red and its child 25 is red, violating the no-red-red rule.

  4. Check the uncle

    The uncle is 10, which is black. A recolor alone would not fix the shape, so a rotation is required.

  5. Rotate and recolor

    25 moves up, 30 moves down-right, and colors are reassigned to restore both invariants.

Predict, then observe

Before you step: If the uncle were red, would a rotation be required?

No. Recolor the parent, uncle, and grandparent; the red-red violation moves upward and may resolve at the root. Rotate only when the uncle is black.
