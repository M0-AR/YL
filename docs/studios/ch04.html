Math, Characters, Strings

Strings look like values but behave like objects, and characters are numbers wearing quotes.

~35 minExpression lab3 objectives5 subgoals
  • Predict the result of mixing strings, characters, and numbers with +.
  • Use string methods without confusing indexes with lengths.
  • Explain why a String cannot be changed in place.

LessonSubgoals

Read the subgoals first. Each one is a small, checkable idea that the worked example and the playground will use.

  1. + is left-associative

    "A" + 1 + 2 groups as ("A" + 1) + 2, producing A12. Put the arithmetic in parentheses when you want 3A.

  2. A char is a small integer

    'A' is a single UTF-16 code unit. 'A' + 1 is an int, so cast back to char to print B.

  3. String indexes run from 0 to length - 1

    substring(start, end) includes start and excludes end. That half-open rule makes length arithmetic predictable.

  4. Strings are immutable

    Methods such as toUpperCase return a new string. The original object never changes.

  5. Math methods are static

    Math.max and Math.round are called on the class. They do not need an object.

Worked exampleStringWorkshop: read the expression tree

The same three values produce different results depending on where the string appears and where the parentheses go.

public class StringWorkshop {
    public static void main(String[] args) {
        String left = "A" + 1 + 2;
        String right = "A" + (1 + 2);
        char next = (char) ('A' + 1);
        String word = "java";
        System.out.println(left + " " + right + " " + next);
        System.out.println(word.substring(0, 2).toUpperCase());
    }
}

  1. Left-associative concatenation

    "A" + 1 becomes "A1", then "A1" + 2 becomes "A12".

  2. Parentheses restore arithmetic

    1 + 2 is 3, then the string concatenation produces "A3".

  3. Character arithmetic

    'A' + 1 is the int 66; casting to char gives 'B'.

  4. Half-open substring

    substring(0, 2) takes indexes 0 and 1, producing "ja".

  5. Immutable result

    toUpperCase() returns "JA"; word is still "java".

Predict, then observe

Before you step: What would word.substring(2) return for "java"?

"va". With one argument, substring runs to the end of the string.

PracticeRebuild the program

A Parsons problem: the lines are correct, but the order is not. Rearrange them until the program would compile and behave as described.
