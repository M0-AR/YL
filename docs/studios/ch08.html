Multidimensional Arrays

A 2D array is an array of arrays: rows are references, and each row can have a different length.

~40 minStructure viewer3 objectives5 subgoals
  • Allocate a rectangular 2D array and a ragged one.
  • Traverse a grid by rows and by columns without swapping indexes.
  • Explain why grid.length is the number of rows, not the number of cells.

LessonSubgoals

Read the subgoals first. Each one is a small, checkable idea that the worked example and the playground will use.

  1. Rows first, columns second

    grid[row][column] is the convention. Swapping the indexes compiles but reads the transpose.

  2. length is per dimension

    grid.length is the number of rows. grid[0].length is the length of the first row.

  3. Ragged arrays are legal

    Each row is a separate array object, so rows can have different lengths. A rectangular traversal must use each row's own length.

  4. A grid is an array of references

    The outer array stores references to row arrays. Copying the outer reference does not copy the rows.

  5. Row-major traversal is cache-friendly

    Visiting a whole row before moving to the next matches how the data is laid out and how most loops are written.

Worked exampleGridAudit: row sums and a column probe

The nested loop visits every cell once. The inner loop uses the current row's length, so the same code would survive a ragged grid.

public class GridAudit {
    public static void main(String[] args) {
        int[][] grid = {
            {3, 5, 7},
            {2, 4, 6},
            {9, 1, 8}
        };
        for (int row = 0; row < grid.length; row++) {
            int rowSum = 0;
            for (int col = 0; col < grid[row].length; col++) {
                rowSum += grid[row][col];
            }
            System.out.println("row " + row + " = " + rowSum);
        }
    }
}

  1. Outer array

    Three row references are created. The outer length is 3.

  2. Row objects

    Each brace pair creates a row array. All three rows happen to have length 3 here.

  3. Outer loop

    row selects one row reference at a time.

  4. Inner loop

    col indexes within that row. The guard uses grid[row].length, not a hard-coded 3.

  5. Report

    Each row sum is printed before the next row starts. No cell is visited twice.
