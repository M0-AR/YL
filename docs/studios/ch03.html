Selections

A branch is a guard: it decides whether the next statement belongs to this path or another one.

~35 minExecution trace3 objectives5 subgoals
  • Trace which branch executes for a given input.
  • Explain short-circuit evaluation and why operand order matters.
  • Avoid the classic assignment-versus-comparison mistake.

LessonSubgoals

Read the subgoals first. Each one is a small, checkable idea that the worked example and the playground will use.

  1. A condition is a boolean expression

    Comparisons such as score >= 90 produce a boolean. Java does not accept an int where a boolean is required.

  2. Branches are checked in order

    The first true branch wins and the rest are skipped. Ordering the tests from most specific to least specific is a design decision.

  3. else binds to the nearest if

    Indentation is for humans. Braces are the only reliable way to show which else belongs to which if.

  4. Short-circuit evaluation skips work

    In a && b, if a is false, b is not evaluated. In a || b, if a is true, b is skipped.

  5. = assigns; == compares

    if (x = 3) is a compile error for ints, but the distinction still matters when the types differ. Read conditions as questions, not assignments.

Worked exampleGradeGate: first match wins

The score is 78. Only one branch should assign a grade, and every later test should be irrelevant.

int score = 78;
char grade;
if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {
    grade = 'B';
} else if (score >= 70) {
    grade = 'C';
} else {
    grade = 'F';
}
System.out.println(grade);

  1. First test fails

    78 is not at least 90, so the A branch is skipped.

  2. Second test fails

    78 is not at least 80 either.

  3. Third test passes

    78 is at least 70. The C branch runs and every later branch is skipped.

  4. Output

    The variable is assigned exactly once, so printing it cannot produce an uninitialized-value error.

Predict, then observe

Before you step: If the tests were reordered with the lowest threshold first, what would a score of 95 receive?

It would receive F, because the first test would succeed and every later branch would be skipped. Order carries meaning.

PracticeRebuild the program

A Parsons problem: the lines are correct, but the order is not. Rearrange them until the program would compile and behave as described.
