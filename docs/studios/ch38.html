JavaServer Pages

A JSP is a template that becomes a servlet; the useful discipline is keeping Java logic out of the markup.

~45 minState machine3 objectives5 subgoals
  • Explain how a JSP is translated into a servlet.
  • Use EL and JSTL to render a collection without scriptlets.
  • Escape user-controlled output to prevent markup injection.

LessonSubgoals

Read the subgoals first. Each one is a small, checkable idea that the worked example and the playground will use.

  1. Translation happens first

    The container translates a JSP into a servlet class, compiles it, and then follows the servlet lifecycle. The first request can pay that cost.

  2. EL reads scoped attributes

    ${names} searches page, request, session, and application scope. The name is a key, not a Java variable.

  3. JSTL supplies control flow

    c:forEach and c:if replace scriptlet loops and branches. The page stays markup-first.

  4. Output is not automatically safe

    A value containing HTML becomes markup unless escaped. Use c:out or an escape function for untrusted text.

  5. The servlet prepares the model

    Queries and business rules belong in the servlet or service layer. The JSP receives attributes and renders them.

Worked exampleNameList: one attribute, one loop

The servlet puts a list in request scope. The page renders it with a tag, not a scriptlet.

<% request.setAttribute("names", List.of("Ada", "Grace", "Linus")); %>
<ul>
  <c:forEach items="${names}" var="name">
    <li><c:out value="${name}" /></li>
  </c:forEach>
</ul>

  1. Prepare the model

    The attribute is request-scoped, so it disappears after this request.

  2. Translate the page

    The container turns the JSP into a servlet. The HTML becomes writes to the response.

  3. Evaluate the collection

    EL resolves names from request scope and exposes it to the loop.

  4. Render each item

    The loop repeats the list item markup for every name.

  5. Escape the value

    c:out escapes HTML characters, so a name containing angle brackets is displayed as text.

Predict, then observe

Before you step: What happens if a name is <script>alert(1)</script> and the page uses ${name} instead of c:out?

The browser receives executable markup, not text. Escaping turns the angle brackets into entities and prevents script execution.
